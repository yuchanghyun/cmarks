# Privacy Policy

**cmarks does not collect, store, or transmit any personal data.**

- cmarks reads Markdown files and folders that you open. Everything is rendered on your Mac. No document content, file name, or usage information ever leaves your computer.
- cmarks has no accounts, no analytics, no telemetry and no advertising.
- **Network access.** The Mac App Store version makes no network connections at all. The version distributed on GitHub checks for updates once a day by downloading `appcast.xml` from `raw.githubusercontent.com` and, if you accept an update, downloads it from `github.com`. This can be turned off in Settings ▸ Behavior. No identifying information is sent with these requests (system profiling is disabled).
- **Web links.** Links to web pages in your documents open in your default browser only when you click them. Images referenced by URL are loaded from their servers only when a document that contains them is rendered.
- **Problem reports.** Help ▸ Report a Problem copies diagnostic text (app version, macOS version, settings, recent log lines) to your clipboard and opens a GitHub issue form in your browser. Nothing is sent unless you submit the form yourself, and you can edit the text before doing so.
- **Quick Look extension.** The extension renders the selected file inside the macOS sandbox and sends nothing anywhere.
- **Session data.** Open workspaces, tabs, window positions and settings are stored locally in your user account (Application Support or the app's container) and can be deleted by removing the app and that folder.

Questions: open an issue at https://github.com/yuchanghyun/cmarks/issues.

# 개인정보 처리방침

**cmarks는 어떤 개인정보도 수집·저장·전송하지 않습니다.**

- cmarks는 사용자가 연 Markdown 파일과 폴더를 읽어 Mac 안에서 렌더링합니다. 문서 내용, 파일 이름, 사용 정보가 컴퓨터 밖으로 나가는 일은 없습니다.
- 계정, 분석 도구, 텔레메트리, 광고가 없습니다.
- **네트워크.** Mac App Store 판은 네트워크에 전혀 연결하지 않습니다. GitHub에서 배포하는 판은 하루 한 번 `raw.githubusercontent.com`에서 `appcast.xml`을 내려받아 새 버전을 확인하고, 사용자가 업데이트를 수락하면 `github.com`에서 내려받습니다. 설정 ▸ 동작에서 끌 수 있습니다. 이 요청에 식별 정보는 실리지 않습니다(시스템 프로필 전송 꺼짐).
- **웹 링크.** 문서 안의 웹 링크는 사용자가 클릭할 때만 기본 브라우저에서 열립니다. URL로 참조된 이미지는 그 문서를 렌더링할 때만 해당 서버에서 불러옵니다.
- **문제 신고.** 도움말 ▸ 문제 신고는 진단 텍스트(앱 버전, macOS 버전, 설정, 최근 로그)를 클립보드에 복사하고 브라우저에서 GitHub 이슈 양식을 엽니다. 사용자가 직접 제출하기 전에는 아무것도 전송되지 않으며, 제출 전에 내용을 고칠 수 있습니다.
- **Quick Look 확장.** 선택한 파일을 macOS 샌드박스 안에서 렌더링하며 어디로도 보내지 않습니다.
- **세션 데이터.** 열린 워크스페이스, 탭, 창 위치, 설정은 사용자 계정 안(Application Support 또는 앱 컨테이너)에 저장되며, 앱과 그 폴더를 지우면 삭제됩니다.
